# Pothole Detection Using AI

An AI-based pothole detection and severity management system developed using YOLOv8 and Streamlit.

## Project Overview

This project uses computer vision and deep learning to detect potholes from images and provide information about their severity.

## Technologies Used

- Python
- YOLOv8
- Computer Vision
- Deep Learning
- Streamlit
- OpenCV
- NumPy

## Model

The pothole detection model was trained using YOLOv8.

The dataset was collected from multiple sources and annotated using Roboflow. The images were then preprocessed and augmented before model training.

## Features

- Pothole detection from images
- AI-based object detection
- Severity management
- Streamlit-based user interface
